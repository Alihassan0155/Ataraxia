This is just a regular piece of paper and this is what it looks like under UV light. What I want to try now though is to see what happens if I add a bit of sunscreen to it. Then I can flip the UV back on and the sunscreen turns completely black. This is because it contains chemicals like octyl salicylate or octocrylene which are able to absorb the UV light. This means that very little of the UV is getting reflected back, which makes it appear black, and I think that's pretty cool.
